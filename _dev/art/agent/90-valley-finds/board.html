Valley Finds v1

Batch 90, 2026-10-29. Four small finds that appear around the FORAGE orb for 1 to 3 seconds; a tap pays bonus food. Each is 24x24 native art pixels (72 dp at x3, so a 48 dp tap target fits inside the art). Ink outline on every find, so it pops in all three light levels.

Rabbit

A wild hare that darts sideways across the grass. One idle pose and a 4-frame run (gather, stretch, reach, push off). It faces right; the game flips it for the other direction.

Berry bush

Four states, one per tap: full, two-thirds, one-third, bare. The silhouette never changes, only the berries, so the tap target stays put.

Leaping fish

A river fish caught mid-leap: rising out of a splash, top of the arc, falling with droplets, and going back in with a crown splash.

Wild honey

A honeycomb in the hollow of an old stump with three bees circling. The stump never moves; only the bees do.
