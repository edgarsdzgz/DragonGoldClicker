# Icon options: Close, Reassign, Soldiers helm (2026-10-26)

The owner asked for more creative Close and Reassign icons and a better helm, from reference
boards of pixel X icons, arrows and knight helmets. These are options, not locked.

- `src/make_options.py` writes `src/options.px` (masks plus color rules, ink outline added).
- Build: the pixkit build of `src/options.px`, then `python build_page.py` for `options.html`.
- What the references share: an X on a button plate or round badge, hollow or bevelled Xs;
  looping arrows, chunky arrows with a 3D underside, two-color pairs; helmets with a rounded
  dome, a dark T opening, a red plume, or a cross visor (the flat-topped box reads poorly).
