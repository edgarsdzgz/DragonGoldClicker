# Research study icons (2026-10-26)

One icon for each of the 13 studies in `src/types/research.ts` (the tree in code: four chains of
three or four). The four category icons reuse official icons: The Dragon = claws, The Army =
shield, The Stores = wheat, The Wall = gate. Grids: `src/make_icons.py` writes `src/icons.px`;
sprites are `icon_res_<study id>.png`. Sheet: `preview/sheet_x6.png`.
